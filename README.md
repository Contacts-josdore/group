# JosDore — La technologie au service de la communauté

Écosystème tech & éducatif africain fondé par **Ulrich Jos Doré HOUNKPE**.

## 🌍 Le projet

JosDore regroupe 4 pôles complémentaires :

| Pôle | Activité | Couleur |
|------|----------|---------|
| 🔵 **Tech** | Maintenance informatique + outils | `#2563EB` |
| 🟢 **Store** | Boutique informatique + livres | `#16A34A` |
| 🟡 **Academy** | Formations + anglais + jeux | `#EAB308` |
| 🔴 **Impact** | Fondation + réseau social | `#BE123C` |

## 📖 Contenu du dépôt

- **`index.html`** — Site principal avec les 4 pôles
- **`charte.html`** — Charte graphique complète (couleurs, typographie, règles)
- **`logos.html`** — Tous les logos dans leurs différentes versions
- **`icones.html`** — Bibliothèque de 78 icônes SVG
- **`guide.html`** — Guide de démarrage et résumé du projet

## 🚀 Lancer le projet

1. Clonez le dépôt
2. Ouvrez `index.html` dans votre navigateur
3. Ou utilisez **Live Server** dans VS Code

## 🌐 Déployer sur GitHub Pages

1. Settings → Pages
2. Source : `main` / `root`
3. Save

Le site sera en ligne sur `https://votre-username.github.io/josdore`
